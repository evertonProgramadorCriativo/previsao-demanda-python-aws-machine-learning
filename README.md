# Previsão de Demanda e Vendas

Projeto pessoal de análise e previsão de demanda com dados de vendas simulados, rodando na AWS.

Tecnologias: Python, Pandas, NumPy, SQL (PostgreSQL/RDS), Scikit-learn, MLflow, Docker, AWS (EC2, S3, RDS) e Streamlit.
